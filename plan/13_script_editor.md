# 13: Script Editor — スクリプトエディタ

## 概要
`engine_core` を利用したオーサリングツール。スクリプト編集、ライブプレビュー（ホットリロード）、Live2D パラメータ調整、3D モデル配置のビジュアル編集を提供する。

## 依存先
- `07_script_system`, `11_ui_system`

## モジュール構成
```
crates/script_editor/src/
├── lib.rs              # クレートルート
├── ui/
│   ├── mod.rs          # エディタ UI メイン
│   ├── editor_panel.rs # スクリプトテキスト編集パネル
│   ├── toolbar.rs      # ツールバー
│   ├── sidebar.rs      # アセットブラウザ
│   └── status_bar.rs   # ステータスバー
├── preview/
│   ├── mod.rs          # ライブプレビューエンジン
│   ├── hot_reload.rs   # ファイル変更検知 + ホットリロード
│   └── viewport.rs     # プレビュービューポート
├── inspector/
│   ├── mod.rs          # インスペクタ
│   ├── live2d.rs       # Live2D パラメータスライダー
│   ├── model3d.rs      # 3D モデル配置 / 回転 / スケール
│   └── save_editor.rs  # セーブデータ JSON 編集
└── project/
    ├── mod.rs          # プロジェクト管理
    ├── config.rs       # プロジェクト設定
    └── asset_browser.rs # アセットブラウザ
```

## タスク

### 1. エディタ UI シェル
- MVVM + Signal ベースの UI（`engine_core` の UI システム利用）
- マルチパネルレイアウト: エディタ | プレビュー | インスペクタ
- メニューバー / ツールバー

### 2. スクリプト編集パネル
- テキストエディタ（シンタックスハイライト）
- タグ入力補完
- エラー表示（パーサエラーのインライン表示）

### 3. ライブプレビュー
```rust
pub struct PreviewEngine {
    engine: engine_core::EngineCore,
    watch: FileWatcher,
}
```

- ファイル変更検知 (`notify` クレート)
- スクリプト再パース → ゲーム画面即時反映
- 現在行からの再生開始

### 4. インスペクタ
- **Live2D**: パラメータ一覧、スライダーでリアルタイム調整
- **3D Model**: 位置 / 回転 / スケールの Gizmo 操作
- **Save Editor**: セーブデータを JSON 形式で表示・編集

### 5. アセットブラウザ
- `assets/` ディレクトリのツリー表示
- ドラッグ & ドロップでスクリプトにアセット参照挿入
- サムネイルプレビュー

### 6. FBX → GLB 変換
- FBX ファイルのインポート
- アニメーション保持 → GLB エクスポート

## テスト計画
- スクリプトパース + プレビュー表示テスト
- ホットリロードのファイル変更検知テスト
- インスペクタのパラメータ変更反映テスト
